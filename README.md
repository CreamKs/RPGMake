# 2D 횡스크롤 싱글 RPG

Unity 6와 C#으로 제작 중인 Windows PC용 2D 횡스크롤 싱글 액션 RPG 프로젝트입니다.

옛날 메이플스토리 계열의 단순하고 직관적인 조작 감각을 참고하되, 포트폴리오에서는 게임의 규모보다 **조작감, 전투 피드백, 안정적인 시스템 구조와 문제 해결 과정**을 보여주는 것을 목표로 합니다.

## 프로젝트를 시작한 계기

기존에는 C++과 Unreal Engine을 중심으로 게임 개발을 경험해 왔습니다.
이번 프로젝트는 처음 사용하는 Unity와 C#을 기초부터 학습하고,
기존에 익힌 게임 프로그래밍 개념을 새로운 개발 환경에서도 직접 적용해 보기 위해 시작했습니다.

단순히 Unity의 기능을 따라 사용하는 것에 그치지 않고,
2D 횡스크롤 RPG를 직접 제작하면서 입력, 물리, 애니메이션, 전투, 데이터 관리 등
게임을 구성하는 주요 시스템을 하나씩 구현하고 이해하는 것을 목표로 하고 있습니다.

최종적으로는 플레이 가능한 게임을 완성하는 것과 함께,
새로운 엔진과 언어를 학습하고 실제 프로젝트에 적용하는 과정을 포트폴리오로 남기는 것을 목표로 합니다.

## 현재 구현 상태 - Week 02

### Player

- Rigidbody2D 기반 좌우 이동
- Alt 점프 및 Alt 키 홀드 시 연속 점프
- GroundCheck 기반 착지 판정
- Platform Effector 2D 기반 원웨이 플랫폼
- ↓ + Alt 입력을 이용한 아래 점프
- Visual 오브젝트 분리를 통한 캐릭터 좌우 반전
- Idle / Run / Jump / Fall / Attack / Hit / Death 애니메이션 연결
- 체력과 피격 후 0.7초 무적
- 피격 시 색 변화와 가로 넉백
- 사망 시 조작과 공격 판정 차단
- 사망 2초 후 테스트 장면 재시작

### Enemy

- 감지 범위 안의 플레이어 추적
- 이동 방향에 따른 Visual 좌우 반전
- 피격 시 색 변화와 가로 넉백
- 피격 중 이동을 중단하고 넉백 종료 후 추적 재개
- 몸체 충돌과 플레이어 접촉 감지 영역 분리
- 플레이어 접촉 피해
- HP가 0 이하가 되면 추적과 접촉 피해 중단 후 제거

### Combat

- Animation Event 기반 공격 타이밍 처리
- AttackPoint 기반 원형 공격 범위
- LayerMask를 이용한 Enemy 판정
- Enemy HP 및 데미지 처리
- 월드 공간 데미지 숫자 표시
- 실험용 Hit Slow
- 공격 적중 시 Screen Shake
- 여러 몬스터를 대상으로 한 전투 검증

### Camera

- 플레이어 추적
- SmoothDamp 기반 부드러운 이동
- 맵 경계 Clamp
- 점프 시 카메라가 과도하게 따라가지 않도록 Vertical Dead Zone
- 공격 적중 시 짧은 Screen Shake

## 현재 플레이 루프

~~~text
이동 / 점프
    ↓
몬스터 감지 및 추적
    ↓
플레이어 기본 공격
    ↓
몬스터 피격 / 넉백 / HP 감소
    ↓
몬스터 처치
~~~

몬스터와 접촉하면 플레이어도 피해와 넉백을 받습니다.
피격 후에는 짧은 무적 시간이 적용되며, 플레이어의 체력이 0이 되면
조작을 중단하고 사망 애니메이션을 재생한 뒤 테스트 장면을 다시 시작합니다.

기본 공격은 한 종류의 공격을 반복해서 사용하는 방식입니다.
공격 도중 피격되더라도 진행 중인 공격은 유지하도록 구성했습니다.

## 개발 방향

초기 목표는 대규모 콘텐츠 제작이 아니라 핵심 플레이 루프를 먼저 검증하는 것입니다.

1. 조작이 즉각적이고 안정적으로 동작할 것
2. 공격 입력과 실제 타격 시점이 자연스럽게 일치할 것
3. 데미지 숫자, 카메라 반응 등 전투 피드백을 확인할 수 있을 것
4. 시스템을 이후 직업, 몬스터, 스킬로 확장할 수 있을 것

6개월 차에는 플레이 가능한 Vertical Slice 완성을 1차 목표로 하며, 필요 시 최대 12개월까지 콘텐츠와 완성도를 확장할 계획입니다.
