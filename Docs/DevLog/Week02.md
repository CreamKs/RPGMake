# 2주차 — 몬스터 추적과 상호 전투
작업 기간: 2026-09-30 ~ 2026-10-02

## 목표와 결과
1주차의 이동·기본 공격을 기반으로 몬스터와 플레이어가 서로 피해를 주고, 피격·사망·재시작까지 이어지는 테스트 전투를 구현했다.
이 기록의 구현 및 검증 결과는 개발자가 로컬 Unity 에디터에서 확인한 결과다. 기록 작성 시점에는 2주차 코드와 장면 변경의 저장소 업로드가 남아 있다.

## 구현 내용
### 몬스터
- 테스트용 오염 슬라임 이미지 적용.
- Visual 자식으로 그림을 분리하고 추적 방향에 따라 X 스케일 반전.
- 감지 범위 안의 플레이어를 가로 방향으로 추적하고 가까워지면 정지.
- 피격 시 짧은 색 변화와 가로 넉백 적용.
- 피격 중 추적이 물리 속도를 덮어쓰지 않도록 IsHit 검사.
- 피격 시간 종료 후 가로 속도를 멈추고 추적 재개.
- 사망 상태에서 추적 및 접촉 피해 중단.

### 플레이어
- PlayerHealth에서 체력과 0.7초 무적 관리.
- 실제 피해를 받은 경우 색 변화와 가로 넉백 적용.
- 넉백 중 이동·점프·새 공격 입력 차단.
- Hit 및 Death 애니메이션 연결.
- 체력 0에서 조작 및 공격 판정 차단.
- 실제 시간 2초 후 현재 테스트 장면 전체를 다시 불러오기.

### 접촉 판정 분리
몬스터 부모의 몸체 충돌체는 바닥 충돌을 담당한다. ContactSensor 자식의 트리거는 플레이어 접촉을 감지한다.

| 설정 위치 | 규칙 |
| --- | --- |
| 몬스터 몸체 충돌체 | Player 레이어 제외 |
| 몬스터 Rigidbody2D | Player를 제외하지 않음 |
| ContactSensor | EnemySensor 레이어, 트리거 활성화, Player 제외 없음 |
| 공격 검색 | Enemy 레이어만 검색 |
| 물리 충돌 매트릭스 | Player와 EnemySensor 접촉 허용 |

감지용 자식에는 별도 Rigidbody2D를 추가하지 않고 부모의 물리 바디를 사용한다. 접촉 피해는 OnTriggerStay2D에서 요청하고 PlayerHealth가 무적 시간으로 적용 빈도를 제한한다.

## 역할 분리
| 스크립트 | 책임 |
| --- | --- |
| PlayerController | 입력·이동·점프·방향과 피격/사망 시 조작 제한 |
| PlayerCombat | 공격 대상 검색 및 피해 전달, 사망 후 판정 차단 |
| PlayerHealth | 체력·무적·피격 효과·넉백·사망·재시작 |
| EnemyAI | 감지 거리와 추적, 방향 전환, 피격/사망 상태 확인 |
| EnemyHealth | 몬스터 체력·피격 효과·넉백·사망 |
| EnemyContactDamage | 접촉한 플레이어에게 피해 요청 |

## 조작감 결정
- 기본 공격은 동일한 공격을 반복한다. 3타 콤보는 제작 범위에서 제외했다.
- 몬스터 넉백은 위쪽 속도를 0으로 설정했다.
- 넉백은 기존의 일정 시간 유지 후 가로 속도 정지 방식을 유지했다. 제안된 점진 감속 코드는 채택하지 않았다.
- 공격 중 피격돼도 피해와 넉백은 적용하되 진행 중인 공격을 유지하는 것이 의도다. 피격에 의한 공격 취소는 넣지 않는다.
- 사망 시에는 공격 판정을 차단한다.
- 재시작은 체크포인트 저장/복원이 아니라 테스트 장면 전체 초기화다.

## 문제 해결
### 넉백이 적용되지 않음
몬스터에 Rigidbody2D가 없어 속도를 적용할 대상이 없었다. EnemyHealth와 같은 오브젝트에 동적 Rigidbody2D를 추가했다.

### 플레이어 몸으로 몬스터가 밀림
물리 몸체 충돌과 접촉 피해 감지를 분리했다. 몸체만 플레이어와 충돌하지 않게 하고 트리거는 접촉을 유지했다.

### 플레이어 접촉 피해가 감지되지 않음
충돌 제외 설정을 점검했다. Rigidbody2D에서 Player를 제외하면 연결된 자식 센서에도 영향을 줄 수 있으므로 제외 설정을 몸체 Collider2D에만 적용하도록 정리했다.

### 공격 적중 시 관리자 참조 오류
HitStopManager.Instance 호출에서 빈 참조 오류가 발생했다. 관리자는 몬스터와 독립된 활성 오브젝트에 두고 장면에 연결하는 방식으로 해결했다. 접촉 피해 코드 자체에는 관리자 참조를 변경하는 처리가 없었다.

### 사망 애니메이션 재시작
모든 상태에서 Death로 진입하는 전환의 자체 전환 가능 설정을 해제했다. 사망 클립은 반복하지 않고 마지막 자세를 유지하도록 설정했다.

## 검증
개발자가 적 3마리를 배치한 수동 전투 검증을 모두 통과했다고 확인했다. 이후 플레이어 피격·사망 애니메이션 연결과 사망 반복 문제 해결도 완료했다고 확인했다. 자동 테스트나 성능 측정 결과를 의미하지 않는다.

| 항목 | 확인 내용 |
| --- | --- |
| 추적 | 감지 범위 내 플레이어 접근 |
| 다수 공격 | 공격 범위 안의 적들에게 피해 전달 |
| 몬스터 피격 | 넉백 후 추적 재개 |
| 동시 접촉 | 플레이어 무적 시간 적용 |
| 플레이어 피격 | 이동 입력 중에도 넉백 유지 |
| 몬스터 사망 | 추적과 접촉 피해 중단 |
| 기존 조작 | 이동·점프·아래 점프 유지 |
| 재시작 | 사망 후 장면 초기화와 전투 재개 |

## 현재 제한
- 적의 발판 끝 감지와 점프는 아직 없다.
- 적 AI는 작은 조건 분기 기반 추적이며 범용 상태 머신은 아직 구현하지 않았다.
- 체력은 콘솔로 확인하며 체력 UI는 아직 없다.
- 저장·체크포인트 복원 기능은 아직 없다.

## 저장소 반영
로컬에서 저장한 Assets, Packages, ProjectSettings 변경과 필요한 .meta 파일을 함께 커밋해야 애니메이터·장면·레이어 설정까지 재현할 수 있다. Library, Temp, Logs 등 생성 폴더는 업로드하지 않는다.
