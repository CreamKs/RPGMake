# 6개월 주차별 개발 계획

## 계획 목적

이 문서는 6개월 안에 전사 캐릭터로 시작부터 엔딩까지 플레이할 수 있는 수직 슬라이스를 완성하기 위한 주차별 기준입니다.

각 주차는 기능 수보다 실제로 실행하고 검증할 수 있는 결과를 남기는 것을 우선합니다. 구현 과정에서 일정이 밀리면 콘텐츠 수를 줄이고 이동, 전투, 성장, 저장처럼 전체 진행에 필요한 기능을 먼저 완성합니다.

스킬 이름과 세부 효과는 아직 확정되지 않았습니다. 계획서에 적힌 스킬 이름은 모두 가칭이며 실제 구현 과정에서 변경할 수 있습니다.

## 1개월 차 - 2D 조작과 전투 기반

| 주차 | 목표 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| Week 01 | 기본 조작 및 공격 검증 | 이동, 점프, 아래 점프, 기본 공격, 몬스터 피격과 사망이 연결됨 | 완료 |
| Week 02 | 몬스터와의 상호 전투 | 몬스터 추적, 양쪽 피격과 넉백, 무적 시간, 플레이어 사망과 재시작이 동작함 | 완료 |
| Week 03 | 기존 이동 시스템을 Tilemap 테스트 맵에 적용 | 실제 타일 지형과 원웨이 발판에서 이동·점프·아래 점프가 정상 동작하고 Pixel Perfect와 카메라 경계를 확인함 | 예정 |
| Week 04 | 첫 프로토타입 안정화 | Player와 Enemy를 프리팹으로 정리하고 오류 수정 후 Windows 테스트 빌드를 남김 | 예정 |

Week 03에서는 발판 판정과 아래 점프를 새로 만들지 않습니다. Week 01에서 구현한 기능을 Tilemap 기반 테스트 맵에 적용하고 발판 가장자리, 높이가 다른 발판, 연속 이동 상황에서 문제가 없는지 검증합니다.

## 5개월 차 - 궁수와 마법사

| 주차 | 목표 | 완료 기준 |

궁수와 마법사의 스킬 이름과 최종 개수는 전사 수직 슬라이스의 완성도와 남은 일정에 따라 정합니다.

## 매주 공통 작업

- 매주 실행 가능한 상태의 빌드를 남깁니다.
- 새 기능을 구현한 뒤 이동, 점프, 공격, 피격, 사망 흐름을 다시 확인합니다.
- 발생한 문제와 해결 과정을 해당 주차 개발 기록에 남깁니다.
- 기능을 추가하면서 기존 Inspector 참조, Prefab, Animator와 Input Action 연결이 깨지지 않았는지 확인합니다.
- 월말에는 다음 기능을 추가하기 전에 일정상 줄이거나 미룰 항목을 먼저 결정합니다.

## 일정 변경 기준

이 계획은 구현 순서와 완료 기준을 정하기 위한 기준이며 고정된 출시 일정은 아닙니다.

전사 수직 슬라이스 완성을 가장 우선하며 일정이 부족하면 서브 퀘스트, 숨겨진 구역, 장비 옵션, 후반 스킬과 추가 지역 순서로 범위를 줄입니다. 이동·전투·성장·저장·보스 진행은 최종 빌드까지 유지합니다.
